# Frontend Mentor - Weather app solution

This is a solution to the [Weather app challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/weather-app-K1FhddVm49). Frontend Mentor challenges help you improve your coding skills by building realistic projects. 



### The challenge

Users should be able to:

- Search for weather information by entering a location in the search bar
- View current weather conditions including temperature, weather icon, and location details
- See additional weather metrics like "feels like" temperature, humidity percentage, wind speed, and precipitation amounts
- Browse a 7-day weather forecast with daily high/low temperatures and weather icons
- View an hourly forecast showing temperature changes throughout the day
- Switch between different days of the week using the day selector in the hourly forecast section
- Toggle between Imperial and Metric measurement units via the units dropdown 
- Switch between specific temperature units (Celsius and Fahrenheit) and measurement units for wind speed (km/h and mph) and precipitation (millimeters) via the units dropdown
- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page

### What I learned
This project is my second react project. I decided to do this because I wanted to challenge myself and see if I felt comfortable using react while building something difficult.  
I started out by planning this project using Notion to highlight the main features and requirements for this project.  
Overall I learnt a lot since I made a lot of mistakes and had many bugs but I overcame them.  
At first I was very intimidated since this was my first time working with an API and I just felt like it was out of my comfort zone, but I think this will definitely be my most memorable project since I learnt so many things I was curious about before like - how to use 2 API's together and also I learnt how loading states and error states work.  
So far I'm enjoying using react and tailwindCSS together it feels more organized and efficient. 




### Continued development
I still have a lot to learn regarding API's. there were at times during this project where i felt like I had no idea how to display the data from the API.  
For example the Hourly Forecast was the hardest since It contained data for all 7 days.  
And I was confused on how to display the data for only one day at a time.  
Going Forward I want to do another API project to cover my knowledge gaps. 



### AI Collaboration
For this project I used ChatGPT to guide me when i was stuck with the API parts. When I didn't know how to do certain things I would ask it to teach me the relevant concepts and quiz me. Also it made me aware of things I didn't know I should do like 'lazy initialization', also I learnt some accessibility syntax like `<dl>, <dt>, and <dd>`.
